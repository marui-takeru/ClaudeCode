# Mini Shikoku 3D × note 発信戦略（v1）

## 1. ポジショニング

**「研究者が AI と一緒に、地元・松山の電車を 3D で走らせてみた」シリーズ**

同じ題材でも、次の3つの軸が重なるところは書き手が少ないので、ここを狙います。

| 軸 | 読者 | 刺さるポイント |
| --- | --- | --- |
| 地域（愛媛・松山・四国） | 地元民、出身者、観光客、鉄道ファン | 「伊予鉄が 3D で動いてる」という見た目の楽しさ |
| 技術（オープンデータ × 3D地図 × AI開発） | エンジニア、GIS・データ可視化に関心のある人 | 「自分の街でも作れるのか」「AI でどこまでできるのか」 |
| 研究（交通・地域・データ分析） | 研究者、学生、自治体・まちづくり関係者 | 「可視化を分析や政策の議論にどう使うか」 |

※ Mini Tokyo 3D は「着想元」と明記し、公式や関係者と誤解される名前・表現は避けます。

## 2. 無料と有料の線引き

コードを GitHub で公開するなら、**コードそのものは売り物にしません**。売るのは「時間の節約」と「解釈」です。

| 区分 | 内容 | 狙い |
| --- | --- | --- |
| 無料 | 作ったもの、動画・GIF、作った動機、全体像、つまずいた点のさわり、今後の予定 | 拡散とフォロワー獲得 |
| 有料（記事の後半） | 手順の詳細、データの入手・整形のノウハウ、AI への指示の実例、ハマりどころと解決策、他都市版への作り替え方 | 「自分でもやりたい人」の時間短縮 |
| 有料マガジン | シリーズ全体（v1〜v5 と番外編）をまとめたもの | 単品より割安にして継続購入につなげる |
| 将来の選択肢 | メンバーシップ（開発の途中経過、リクエスト受付）、講座や受託（自治体・観光・教育向けの可視化） | 記事の外での収益 |

価格の目安：単品の有料パートは 300〜500円、マガジンは 1,500〜2,000円 程度から始め、反応を見て調整します。
（手数料や販売機能の条件は note の最新の規約で確認してください。）

## 3. シリーズ構成案

| 回 | 内容 | 有料パートの中身 |
| --- | --- | --- |
| vol.1（今回） | 四国版プロトタイプ完成、仕組みの全体像 | 手順の全体、データ整形、AI への指示の実例 |
| vol.2 | 線路の形を実際の線形に（国土数値情報 N02 / OSM） | GIS データの扱い方、座標合わせのコツ |
| vol.3 | 実ダイヤ化（GTFS / GTFS-JP の取り込み） | 時刻表データの構造と変換方法 |
| vol.4 | バス・フェリー・しまなみ方面への拡張 | 複数の交通手段の統合 |
| vol.5 | 研究への応用：到達圏・運行本数の可視化 | 分析手法、指標の考え方 |
| 番外編 | 「あなたの街版」の作り方テンプレート | 汎用の作り替え手順 |

**毎回の締めに「次回予告」と「読者リクエスト募集」**を入れ、連載として読まれる流れを作ります。

## 4. 集客の導線

1. **X（旧Twitter）に 15〜30 秒の動画・GIF**（夕方ラッシュを ×60 で、道後温泉駅に坊っちゃん列車が入ってくる場面など）→ note へのリンク。いちばん効果が大きい部分です。
2. ハッシュタグ：#松山 #愛媛 #伊予鉄 #坊っちゃん列車 #オープンデータ #MapLibre #ClaudeCode など。
3. デモを **GitHub Pages で公開**し、読者がその場で触れるようにする（記事の説得力が大きく変わります）。
4. 技術者向けには Qiita や Zenn に要約記事を書き、詳しい版として note に誘導する。
5. 地元のコミュニティ（Code for 系の団体、大学、地域メディア）に紹介する。研究者という肩書きは信頼につながります。

## 5. 公開前のリスク確認

- [ ] **駅データ.jp の利用規約**（特に商用利用・再配布の条件）を確認する。有料記事と結びつくので重要です。難しければ国土数値情報（出典を書けば商用も可、のもの）に切り替えます。
- [ ] 地図の出典表記（© OpenStreetMap contributors / OpenFreeMap / 国土地理院）を画像にも入れる。
- [ ] 事業者のロゴや車両写真を使わない。社名・路線名は事実の記述の範囲にとどめる。
- [ ] 「列車位置は推計で、実際の運行ではない」と記事にも明記する（誤解やクレームの予防）。
- [ ] 「Mini Tokyo 3D を参考にした」と書き、公式・関係者と誤解されないようにする。
- [ ] AI を使って開発したことを隠さない（今は隠さないほうが価値になります）。

## 6. 指標（最初の3か月）

| 指標 | 目安 |
| --- | --- |
| vol.1 の閲覧数 | 1,000〜 |
| スキ数 / 閲覧数 | 5% 以上なら題材は当たり |
| 有料部分の購入率 | 閲覧の 1〜3% |
| フォロワー | 連載3本で 100〜 |
